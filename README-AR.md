# FHN.M Android

هذا مشروع Android أولي يفتح تطبيق المكتبة المنشور على Hatchable داخل WebView.

## إعداد البناء
- التطبيق: FHN.M
- package ID: `com.fhnm.gestionbibliotheque`
- عنوان التطبيق المستضاف: `https://gestion-de.hatchable.site/`
- البناء عبر GitHub Actions ينتج APK تجريبياً (debug APK)، وليس إصداراً موقعاً للنشر العام.

## طريقة الاستخدام
انسخ محتويات هذا المجلد إلى جذر مستودع `FHN-M1` مع الحفاظ على بنية المجلدات، ثم افتح تبويب Actions وشغّل `Build FHN.M APK`.
بعد نجاح البناء، افتح نتيجة التشغيل ونزّل artifact باسم `FHN-M-debug-apk`، ثم فك ضغطه لتحصل على `app-debug.apk`.

## ملاحظات
- هذا الغلاف لا ينسخ قاعدة البيانات أو الشيفرة الخلفية؛ إنه يعرض التطبيق المنشور عبر الإنترنت.
- يحتاج الاتصال بالإنترنت.
- اختبر تسجيل الدخول والوظائف الأساسية على جهاز Android قبل الاعتماد عليه.
- لا توجد مفاتيح توقيع خاصة ضمن هذا المشروع.
